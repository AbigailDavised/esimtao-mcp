# EsimTao Gemini CLI Extension

Connects Gemini CLI to **EsimTao** (`https://esimtao.com/api/mcp`), providing stateless MCP tools for:
- Travel data usage calculations based on daily app consumption (Maps, Social, Video, VoIP)
- Global phone hardware eSIM compatibility checks (US eSIM-only vs HK dual physical nano-SIM)
- International roaming and provider price benchmarks (Airalo, Nomad, Ubigi, Holafly)
- China travel eSIM and Great Firewall (GFW) bypass routing guide

Website: https://esimtao.com
